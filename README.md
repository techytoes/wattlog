# Wattlog

Zero-root macOS Apple Silicon power, sleep-insomnia diagnostics, safe-by-default Keep-Awake (Caffeine), and grouped process monitor—built with Tauri v2 (Rust + React/TypeScript) and a crisp monospace dot-matrix UI inspired by `govijr/fix-storage`.

See [docs/SPEC.md](docs/SPEC.md) for the research-backed v1 feature cut, zero-root API architecture, and design system.
